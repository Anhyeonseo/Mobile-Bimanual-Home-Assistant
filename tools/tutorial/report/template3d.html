이 브라우저에서는 3D 화면을 열 수 없습니다.
  1. 초록·노랑으로 물든 점이 고른 물체입니다. 초록은 통과, 노랑은 보류입니다.
  2. 주황 ㄷ자가 1순위 집게 자세, 하늘색은 나머지 후보입니다. 집게 사이에 물체가 있고 책상에 닿지 않는 후보만 남겼습니다.
  3. 납작한 물체는 위에서 수직으로 짧은 폭을 집는 규칙 후보를 1순위로 둡니다. 화면에 규칙이라고 표시됩니다.
  4. 보류된 물체의 후보는 볼 수 있지만 실행 후보에서는 제외했습니다.
  5. 컵 표면에 뚫린 빈 곳이 거리를 재지 못한 자리입니다. 컵 주변 후보가 흩어지는 이유를 여기서 볼 수 있습니다.
  6. 집게 크기는 GraspNet 기본값(최대 10cm)이며 실제 로봇 집게 치수가 아닙니다. 실제로 집어본 결과가 아닙니다.
