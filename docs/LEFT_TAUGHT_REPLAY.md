# 왼팔 촬영용 집게 조정 r5

집게의 닫힘·들어 올리기 목표를 1990에서 1970으로 조정했습니다. 원래 실측값과 영점은 보존하고, `gripper_close_extra_raw: 20`을 별도로 기록합니다. 나머지 팔 자세와 속도는 기존과 같습니다.

기존 펜 집기 기록에서 접촉 1984에 대해 목표 1963을 유지했던 방식을 참고했습니다. 재조립 후 좌표가 달라졌으므로 과거 절대값을 복사하지 않았습니다. 새 목표의 실제 파지력은 아직 확인하지 않았습니다.

젯슨과 STM32의 집게 완료 허용 오차는 49087 µrad(32 raw)로 일치시켰습니다. 20 raw의 추가 닫힘과 12 raw의 측정 여유를 허용하며, 열린 집게를 완료로 처리하지 않습니다. 팔 관절 제한·속도·고장 정지는 유지합니다.

소프트웨어 검사 54개(접촉 후 들기/복귀 및 열린 집게 거부 포함), 새 목표를 사용한 실제 C 실행기 검사 103개, 펌웨어 빌드를 통과했습니다. 실제 물체 집기 성공을 보증하는 결과는 아닙니다.

제어기 전환 뒤 젯슨에서:

```bash
cd ~/robot/releases/selected-demo-r5
python3 tools/run/play_left_demo.py play --execute
```

현재 자세에서 Home으로 이동한 뒤 접근→집는 위치→집게 닫힘→들어 올리기 순서로 진행합니다. 초기 준비 중 토크가 풀리므로 팔을 받칩니다. 들고 유지 중 `return`+Enter로 내려놓기, Home에서 `run`+Enter로 반복, `q`+Enter로 정지합니다. 정지 때 토크가 풀릴 수 있습니다.
