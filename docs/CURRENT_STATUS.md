# 현재 진행 상황

기준일: **2026-11-16**. 마지막 실행 기록과 사용자 확인을 정리한 것이며 실시간 장치 조회가 아니다.

**로봇 작업은 중단 상태다. 현재 우선순위는 수납장 기준 TF·캘리브레이션, 집기 최적화와 자동화이며,
최종 목표는 온디바이스에서 요청부터 실제 완료까지의 시간과 사용자 개입을 줄이는 것이다.**
개발 순서와 현실적인 허용 오차 원칙은 [로드맵](ROADMAP.md)을 따른다.

## 확인한 기능과 남은 범위

| 영역 | 확인한 내용 | 아직 확인하지 못한 것 |
|---|---|---|
| 지도·주행 | 라이다/RGB-D 지도, 목적지 자율 이동·회전, 상자 우회·침입 정지, 기존 가구 위치 갱신 시험 | 장시간·다양한 환경 운용, 집 전체 자동 탐색 |
| 수납장 기준 정지 집기 | S3 흰색 리모컨 집기·들기 성공 1회로 사용자 수락 | 위치·방향별 반복성, 관측된 약 8mm 접촉 오차의 원인 |
| 좌표·높이 | 공식 모델과 촬영 상태 연결, 정지 고정 노출·광각 촬영. **`yeoeun/extrinsic-calibration` 브랜치: 11/17 실측 카메라 6자유도·팔 영점·오른팔 장착·리프트 배율/영점 묶음을 프로필에 반영**(마커 교차 검증 15.8→10.5mm, lateral 0.7–3mm) | 실물 집기 전후 비교, 손가락 끝(TCP) 검증, 중력 처짐·서보 추종 오차 보정(런타임 미지원) |
| 집기용 정차 | 형상·장축·팔 도달성을 고려한 후보와 실제 베이스 이동 | 작은 XY 잔차의 수렴, 이동 후 반복 집기 |
| 고정 손가락 | 관측 단면 경계에 고정면 결합, 벌림 재계산·경로 검사 보완 | 수정 목표와 실제 손가락 위치의 일치, 수정 후보 실물 집기 성공 |
| 통합 제어 | 양팔·리프트 유지, 주행·집기 연결 일부와 실패 로그 | 오른팔 간헐 읽기 오류 원인, 마지막 오류 후 전체 제어기 정지 완료 응답 |
| 언어·전체 작업 | PC 로컬 모델과 텍스트 요청·확인·취소 연결, 모의/기록 기반 실행 | 온보드 언어 처리, 개입 없는 이동→집기→운반→놓기 전체 수행 |

정지 위치 안정화·미세 정렬·광각 촬영은 배포 및 실물 시험 이력이 있다.
이를 여전히 “젯슨 적용 전”이라고 표시하지 않는다. 적용과 성능 수락은 별개이며 XY 미세 정렬은
미수렴 기록이 있다. 저장 관측 집기도 실제 실행까지 연결했으나 성공·완료로 검증되지 않았다.

## 마지막 실물 상태

- `fixed-contact-pick-03`, boot86: open 및 준비 자세 복귀를 포함한 pregrasp 완료 후, 수직 approach 약 6.3초에 중단했다. **close/probe/lift/carry는 실행하지 않았다.**
- 최초 오류는 펌웨어 `BIMANUAL_TRACKING_FAULT`이며 오른팔 읽기 실패 count4, HAL_TIMEOUT3, parser_reject1을 기록했다. 전원·배선·펌웨어 경계 중 원인은 미확정이다.
- 오류 직전 베이스 속도는 0, 리프트는 높이 0m·fault0이고 플랫폼 관측은 수락됐다. 이번 실패를 리프트 높이 판정 문제로 분류하지 않는다.
- STOP 응답만으로 전체 제어기 정지 완료는 확인하지 못했다. **사용자가 실제로 모두 정지했고 양팔·리프트 받침을 유지한다고 확인했다.** 마지막 상태는 모터 ON·정지 잠금이며 이후 재시작·토크 변경·추가 이동은 없다.
- 리모컨은 원래 탁자 위이고 집게는 비어 있다. 앞선 `fixed-contact-pick-02`의 “리모컨 잡힘” 답변은 사용자가 정정했다. 해당 실행의 lift 완료는 관절 동작 완료이며 물체 들기 성공이 아니다.
- 사용자는 고정 손가락이 물체 바깥 대신 안쪽을 향하는 문제를 계속 관찰했다. 모델 경로 통과와 새 영상의 물체 위치 일치는 실제 손가락 정확도를 증명하지 않는다.

문서 작성으로 이 상태를 새로 측정한 것으로 갱신하지 않는다. 사용자가 방향을 정한 뒤 다시
지시하기 전까지 과거 실행 승인이나 후보를 재사용해 자동 재출발하지 않는다.

## 다음 개발의 출발점

1. 기존 보정 도구와 기록에서 실제 접촉 오차·반복성을 어떻게 구분할지 정한다. 추측에 의한 팔 영점 변경은 하지 않는다.
2. 오른팔 응답 문제를 고정 집기 자동화의 장애로 함께 다룬다.
3. 수납장 고정 위치의 관측→후보 선택→집기→실제 성공 확인을 연결하면서 첫 시간 기준값을 얻는다.

위 항목은 개발 방향이며 지금의 로봇 실행 명령이 아니다. 상세 목표와 완료 기준은
[로드맵](ROADMAP.md)에만 관리한다.
