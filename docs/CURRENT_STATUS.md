# 현재 진행 상황

기준일: **2026-11-16**. 사용자 재개 요청으로 정지 위치 안정화·광각 촬영을 젯슨에 적용하고 조회 검증을 마쳤다. 이번에는 모터 이동·힘 켜기·펌웨어 설치 없이 실행 준비까지만 진행했다. 마지막 실제 이동은 11월 15일이다.

## 지금 어디까지 됐나

**정지 상태 집기는 S3 수락을 받았다. 지도 생성·목적지 이동·장애물 대응·기존 가구 위치 갱신은 실제 장치에서 확인했고, 현재는 집기 좋은 베이스 자리 선정과 마지막 정렬을 보완하는 S4b 단계다. S5는 로컬 언어 모델과 작업 연결을 준비했지만 실물 전체 배달은 아직 완료하지 않았다.**

|---|---|---|
| S0 설치 조사 | 장치 구성, 3륜 베이스, LDS-01 수신·장착 근거, 백업 구조 | 설치 변경 시 구성 갱신 |

## 마지막 실물 결과

11월 15일 `directional-base-02`에서 방향 우선 후보 `fixed-left-0-0-60-1`로 이동했다.

- 기존 호스트 `s4-local-50599212da44`, 펌웨어 `0x2492D`를 사용했다. 재설치나 재시작 없이 준비·이동했다.
- 갱신된 탁자 지도로 실제 경로를 확인한 뒤 실행했고 `SUCCEEDED`와 바퀴 정지를 확인했다.
- 종료 순간 목표 대비 추정 잔차는 약 **1.4cm·2.3°**, 정지 후 마지막 관측은 약 **2.9cm·3.2°**였다. 라이다 추정값이며 실측 정확도가 아니다.
- 정지 후 위치 추정이 변했으므로 마지막 숫자를 고정 보정량으로 쓰지 않는다.
- 리프트는 최하단이다. **+1cm 상승과 집기는 실행하지 않았다.**

자세한 기록: [S4b 실행 기록](S4B_EXECUTION_PLAN.md). 실행 원본은 로컬 `output/s4b-remote-trial-20261115/directional-base-02-review/`에 보관한다.

## 이번까지 바뀐 주요 동작

- **주행 연결:** 검증된 3륜 텔레옵 변환을 재사용하고 Nav2 출력과 설치 상한을 일치시켰다. 미전송 패킷 처리 때문에 STOP 전달이 막히던 경로와 시작 조회 소유권 회수를 보완했다.
- **사용성:** 주행 전 팔·리프트 유지 상태를 확인한 뒤 이동 중에는 바퀴 중심으로 조회한다. 바퀴 온도 단발 급등은 새 응답으로 확인하고, 지속 고온·응답 실패는 정지한다.
- **지도:** 오류 종료 구간의 유효 원본도 연결한다. 라이다 뒤쪽 자기 가림을 반영하고 RGB-D 상부 형상을 합친다. 주행 폭은 하단 베이스가 아니라 고정 리프트/장착대까지 포함한다.
- **가구 이동:** 같은 가구의 새 위치가 확인되면 옛 점유 기여를 교체한다. 원본 지도와 이력은 보존하며, 새 미등록 물체는 임시 장애물로 취급한다.
- **집기 자리:** 장축이 분명한 물체에는 도구 접근 방향의 수평 투영을 맞추고, 고정 손가락·관절 여유·과도한 신전을 고려한다. 최종 시야를 요구하지 않는 저장 관측 방식도 분리했다.
- **높이:** 여은 보정 결과의 높이 성분만 적용했다. 고정 16ms 노출·정지 다중 촬영에서 탁자 높이 반복성을 확인했으며 기존 -9.1mm를 중복 적용하지 않는다.
- **언어·앱:** PC 로컬 Qwen3-4B와 텍스트 작업 흐름을 연결했다. 한 물체·구체적 목적지·작업당 한 번의 실행 확인이 첫 범위다.

## 아직 해결됐다고 말할 수 없는 것

- 오른팔 간헐 수신 오류와 온도 바이트 급등의 모든 원인.
- 라이다 추정의 실제 절대 정확도, 하중에 따른 팔/카메라 처짐.
- S3에서 관찰한 약 8mm 접촉 오차의 원인. 중력 처짐은 가설이며 추가 상수로 보정하지 않았다.
- 다른 물체·장면에서의 베이스 선정과 반복 집기, 실제 운반·놓기.
- 집 전체 자동 탐색. 전원선 문제로 배터리 도착 뒤 실물 검증한다.

## 다음 재개 순서

1. 현재 받침·전원·물체/로봇 위치를 확인하고 새 실행본으로 자세 유지·시작 대기를 준비한다. 자동 이동은 없다.
2. 기존 승인 목표를 최신 관측으로 다시 확인한 뒤 미세 정렬을 시험한다. 바뀐 목표는 사용자 확인 후 진행한다.
3. 리프트 높이 → 새 촬영 또는 저장 좌표 추적 → 전체 팔 경로 검사를 연결한다.
4. 집기·운반·놓기, 이후 S5 자연어 전체 작업을 실물로 검증한다.
