# 왼팔만 연결한 집기 촬영

왼팔의 모터 6개만 연결하여 자세를 저장하고 순서대로 재생한다. 오른팔 연결은 필요 없다. 카메라, 베이스, 리프트는 사용하지 않는다.

이 도구는 전용 STM32 펌웨어 `0x00024A01`과 함께 사용한다. 양팔 펌웨어 `0x00024908`에서는 실행하지 않는다. `inspect`로 버전·관절 수 6·보정 일치·정지 잠금을 확인한다. 펌웨어 교체는 왼팔과 리프트를 받치고 모터 전원을 끈 상태에서 별도로 수행한다. 도구 자체는 펌웨어를 쓰거나 잠금을 해제하지 않는다.

## 자세 저장

왼팔을 받친 상태에서 모터 전원을 켠다. 시작 시 왼팔의 토크가 해제된다. 젯슨 터미널에서:

```bash
cd ~/robot/releases/selected-demo
python3 tools/run/fixed_pick_left.py inspect
python3 tools/run/fixed_pick_left.py teach --file output/left-pick.json
```

손으로 자세를 맞추고 이름을 입력한 뒤 Enter를 누른다. 입력은 이동 명령이 아니라 현재 측정값을 저장하는 명령이다.

| 입력 | 자세 |
|---|---|
| `home` | 기본 자세, 그리퍼 열림 |
| `approach` | 물체 바로 위, 같은 열림 유지 |
| `grasp` | 집을 위치, 같은 열림 유지 |
| `closed` | 팔 위치는 그대로, 그리퍼만 물체에 맞게 닫음 |
| `lift` | 들어 올린 자세, 같은 닫힘 유지 |
| `show` | 저장한 자세 목록 |
| `done` | 자세 관계·관절 경로 검사 후 종료 |
| `q` | 저장된 내용을 남기고 종료 |

왼팔 실측값 6개만 저장한다. 이전 양팔 형식의 자세 파일을 자동 변환하거나 오른팔 값을 만들어 채우지 않는다. 같은 이름을 다시 입력하면 그 자세를 교체한다.

## 검사와 재생

```bash
python3 tools/run/fixed_pick_left.py check --file output/left-pick.json
```

통과하면 왼팔을 저장한 home으로 맞춘다. 첫 시험은 물체 없이 경로를 확인한다. 아래 명령은 초기화 때 토크를 해제한 뒤 조건이 맞으면 실제 이동을 시작한다. 왼팔을 받친 상태에서 시작한다.

```bash
python3 tools/run/fixed_pick_left.py play --file output/left-pick.json --execute
```

`home → approach → grasp → closed → lift`로 이동하고 마지막 자세를 계속 유지한다. 대기 안내가 나온 뒤 `return` + Enter로 원래 위치에 내려놓고 기본 자세로 돌아온다. 기본 자세에서 `run` + Enter로 반복한다. 왼팔과 물체를 받친 뒤 `q` + Enter로 종료한다. 이동 중 취소는 `q` + Enter 또는 Ctrl+C이며, 종료·오류·통신 끊김 때 토크가 풀릴 수 있다. 종료 후 정지 잠금이 설정되므로 연결 문제를 해결하지 않은 채 자동 재시작하지 않는다.

움직임은 관절 각도를 부드럽게 이어 주며 손으로 지나간 중간 경로나 직선 경로를 재현하지 않는다. 검사 통과는 실제 충돌 없음이나 집기 성공을 보증하지 않는다.

## 구현·검증 범위

왼팔 전용 펌웨어는 USART1만 모터 통신 장치로 등록하며 UART4를 초기화하지 않는다. 오른팔·모바일 명령과 양팔 이동 요청을 거절한다. 통신 패킷은 기존 고정 길이를 유지하되 사용하지 않는 오른팔 칸은 0, 존재 비트는 0, 피드백 나이는 UINT32_MAX로 표시한다. 저장 파일과 사용자용 어댑터는 왼팔 6개 관절만 노출한다.

기존 속도·관절 범위·현재 home·출발 직전 자세·피드백·watchdog·정지 확인 조건을 유지한다. 오른팔 없이 촬영·복귀·재촬영, 60초 자세 유지, 취소·입력 종료·피드백 유실·정지 응답 유실을 소프트웨어로 검사한다. 실제 C 전송/관측/자세 저장/완료 판정도 PC용 가상 하드웨어로 검사한다. 물리적 집기는 사용자의 자세 저장과 첫 경로 확인 이후에 검증한다.
