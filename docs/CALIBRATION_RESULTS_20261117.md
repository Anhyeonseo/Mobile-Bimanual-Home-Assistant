# 카메라 + 팔 외부 보정 현장 기록과 결과 (2026-11-16 ~ 17)

작성: 여은 · 브랜치 `yeoeun/extrinsic-calibration` · 현장: 현서 집 로봇 (Jetson, S3 펌웨어 임시 설치)

발표 자료용 정리다. 진행 중인 기록이며, 새 결과가 나오면 아래 "진행 기록"과 "결과"를 갱신한다.
숫자는 모두 이 기록 시점의 1차 분석이며 로봇 설정(프로필)에는 아직 반영하지 않았다.

---

## 1. 왜 다시 했나

| 문제 (11/13 촬영, 11/14 분석) | 결과 |
|---|---|
| 팔 끝 오차가 거의 줄지 않음 | 팔 마커 검증 오차 8.0/11.2mm → 7.8/10.4mm |
| 카메라 x·y·yaw가 정해지지 않음 | 평면은 정보를 주지 않고, 팔 쪽 값(어깨 영점, 마커 부착 위치)과 맞바꿔짐 |
| 영점과 중력 처짐, 2.7% 길이 불일치를 구분하지 못함 | 원인 미확정 |
| 데이터 품질 | 토크를 끈 채 손으로 잡고 촬영, 마커 헐거움(2묶음 버림), 촬영 중 리프트 2·12mm 하강, 오른팔 자세 편중 |
| 일부만 적용됨 | 높이 행만 사용. 카메라와 팔 보정은 같이 넣어야 하는 묶음 |
| 집기 증상 | S3 집기에서 목표보다 약 8mm 아래를 잡음 |

## 2. 바꾼 방법론

| 바꾼 것 | 이유 |
|---|---|
| **토크를 켠 자동 촬영 사진만 보정에 사용** | 손으로 잡으면 하중이 매번 다르다. 서보가 자세를 잡은 상태를 측정 |
| 사람이 먼저 손으로 훑은 공간 안에서만 로봇이 이동 | 로봇 몸체 충돌 모델이 없음 |
| 명령값과 실제 엔코더 값을 둘 다 기록 | 중력 때문에 서보가 덜 가는 양(추종 오차)을 처음으로 측정 |
| 같은 자세 반복 방문 | 반복성과 유격 측정 |
| 양팔 마커 id 분리(왼 4, 오른 5), 단단한 판 + 박스테이프 | 오인식, 헐거움 방지 |
| 광각 1280×720 + 고정 노출 16ms 평면 촬영 | 실제 집기 촬영 설정과 같게. 자동 노출은 탁자 높이가 약 6mm 달라짐 |
| 마커, 표적지, 체커보드 실측(캘리퍼) | 2.7% 불일치를 독립 측정으로 끊기 |
| 리프트 높이를 엔코더로 계산 | 손으로 맞춘 높이 대신 최하단 기준 엔코더 이동량 |

## 3. 진행 기록 (현장에서 생긴 문제와 해결)

| # | 문제 | 원인 | 해결 |
|---|---|---|---|
| 1 | 촬영 도구가 시작부터 거부 | 도구는 S3 펌웨어(0x24911) 전용, 로봇은 S4(0x2492D) | S3 임시 설치(설치 전 전체 flash 백업 SHA256 `8dae4b9e…`), 복구 경로 `s4-unified-e004bef4f622/install.sh` 확인 |
| 2 | `flash.sh`가 메시지 없이 멈춤 | 11/13 설치 기록 폴더가 남아 있으면 종료하는 조건 | 지우지 않고 이름 변경으로 보존 후 설치 |
| 3 | 노트북에서 Jetson 접속 불가 | 공유기의 2.4GHz ↔ 5GHz 대역 간 격리 | 노트북을 2.4GHz로 고정 |
| 4 | 하드웨어 수리(베이스 고정, 무게 추가)로 카메라 자세 변화 가능 | – | 카메라 자세가 들어가는 평면 사진만 재촬영. 렌즈 사진은 유지 |
| 5 | 바퀴 3개 무응답 | 수리 중 바퀴 쪽 배선 분리 | 재연결. 정지 확인에 바퀴가 필요하므로 우회하지 않음 |
| 6 | 오른팔 6개 모터 동시 무응답(여러 번) | 오른팔 케이블·전원 접촉(기존 C01 문제) | 재연결 |
| 7 | 훑기 도중 제어기 잠김(5회) | 팔이 관절 범위 끝에 닿음(어깨 0.1°, 손목 굽힘 0.7°, 손목 회전 0.4°), **받침 위 쉬는 팔이 미끄러져** 팔꿈치가 범위 초과(177 count) | 범위 끝 즉시 경고음 추가, 휴식 자세 여유 확보와 테이프 고정 |
| 8 | 휴식 자세에서 촬영 자세로 가는 길이 연결 안 됨 | 훑기마다 휴식 자세가 달랐음 | 휴식 자세 기준을 마지막 훑기 시작점으로(`--rest-own`), 실시간 안내 도구(`rest_check`) |
| 9 | 자동 촬영 중 정지 2회("SAMPLE_DISCONTINUITY") | 계획은 정상(한 틱당 최대 1,745µrad, 한도 9,000). 27번은 펌웨어의 대체 코드이고, 실제로는 **모터 명령 전송 중 통신 오류 1회**(dispatch `failure_count=1`)로 안전 정지. 두 번 모두 오른팔 이동 중 | 오른팔만 다시 실행(`--only-arm`). 이후 오른팔 30장 완주 |
| 10 | 손으로 맞춘 리프트 높이 불확실 | 줄자 대신 엔코더 사용 | 최하단 엔코더 3900 측정 → 투어 높이 45.9mm |

## 5. 결과 (1차 분석)

### 5.1 데이터 품질

| | 11/13 (토크 끔, 손으로 잡음) | 11/17 (토크 켬, 자동) |
|---|---|---|
| 사진 한 장당 맞춤 오차 | 약 4–5 px | **약 1.1–1.6 px** |

### 5.2 카메라

| 항목 | 11/14 후보 | 11/17 | 비고 |
|---|---|---|---|
| pitch / roll | 46.09° / −1.22° | 45.68° / −1.12° | 하드웨어 수리 후에도 0.4° 이내로 일치 |
| 높이 z | 1010.0mm | 1007.5mm | |
| 바닥·탁자 높이 오차 | – | 약 1–3mm (지금 프로필 9.4 / 4.5mm) | |
| 렌즈 초점거리 fx | 공장값 617.6 | 체커보드 추정 618.1 (0.08%) | 렌즈는 2.7% 원인이 아님. 왜곡은 모서리 사진 부족으로 미확정 |

### 5.3 서보 추종 오차 (명령 대비 실제, 촬영마다 기록)

| 관절 | 대표값 |
|---|---|
| 어깨 | 10–14 raw (약 0.9–1.2°) |
| 팔꿈치 | 3–10 raw |
| 손목 굽힘 | 최대 15 raw (약 1.3°) |

어깨 1°는 팔 끝에서 약 5mm다. 집기 명령에 이 오차를 보정하는 경로가 런타임에 없다.

### 5.4 팔 끝 오차의 방향

왼팔 검증 사진 기준(영점만 보정한 모델):

| 방향 | 오차 |
|---|---|
| 좌우·상하(카메라 화면 방향) | **약 1mm** |
| 카메라 시선 방향(깊이) | 약 15mm, **항상 같은 쪽**(평균 −18.6mm, 흩어짐 6mm, 거리의 2.6%) |

고정 손가락 여유(약 2mm)가 걸린 좌우 방향은 이미 1mm 수준이다. 남은 오차는 한 방향으로 치우친 계통 오차다.

### 5.5 핵심 발견: 리프트 판(양팔)이 프로필보다 약 14mm 낮음

- 리프트 높이를 엔코더 실측(45.9mm)으로 넣으면, 오른팔 장착 보정이 높이 방향 **−16.9mm**로 나오고, 왼팔은 깊이 방향 **약 −11mm**가 남는다.
- 리프트 높이를 32mm로 가정하면 두 팔 모두 맞는다(왼팔 검증 오차 15.1 → 3.7mm, 오른팔 높이 보정 −3.1mm).
- 즉 **양팔이 같은 방향으로 약 14mm 낮다.** 카메라 높이는 바닥·탁자로 1–3mm 안에서 맞으니 카메라 문제가 아니다.
- 런타임도 리프트 높이를 최하단 이후 엔코더로 계산하므로 이 오차가 그대로 집기에 들어간다. 팔이 모델보다 낮으면 집게가 목표보다 낮게 간다. **S3의 "약 8mm 아래" 관찰과 방향이 같다.**
- 리프트 높이 1개만 찍어서, 일정한 오프셋인지 높이에 비례하는 배율인지는 아직 구분하지 못했다. 리프트 기울기까지 풀어 주는 모델 F가 교차 검증에서 가장 좋았다(왼팔 3.9mm, 오른팔 7.0mm, 전체 5.8mm).

### 5.6 반복성

| 팔 | 반복 방문 자세 수 | 카메라 마커 위치 흩어짐(중앙값) | 측정 관절값 흩어짐 |
|---|---|---|---|
| 왼팔 | 3 | 4.0mm | 0.9° |
| 오른팔 | 8 | 7.0mm (최대 19mm) | 0.26° |

오른팔은 관절값이 거의 같은데 마커 위치가 더 흩어진다. 마커가 작게(약 46px) 비스듬히 찍혀 깊이 방향 PnP 잡음이 큰 영향으로 보인다.

### 5.7 모델 비교 (5겹 교차 검증, 팔 마커 중앙값)

| 모델 | 왼팔 | 오른팔 | 전체 | 95% |
|---|---|---|---|---|
| 지금 프로필 | 50.4 | 16.2 | 28.7 | 58.2 |
| A 영점 | 18.9 | 9.5 | 14.1 | 27.4 |
| B 영점 + 링크 | 14.0 | 8.2 | 10.5 | 20.3 |
| C 영점 + 처짐 | 13.5 | 7.1 | 10.7 | 18.8 |
| F 영점 + 처짐 + 리프트(기울기) | **3.9** | **7.0** | **5.8** | 15.9 |

(지금 프로필의 50mm는 리프트 높이 오프셋이 보정되지 않은 영향이 크다.)

## 6. 남은 일

- [ ] **집게 끝 대기**: 카메라가 본 십자와 팔 끝을 직접 비교해 14mm를 독립적으로 확인
- [ ] **리프트 높이 1–2개 추가 자동 촬영**: 오프셋과 배율 구분. 원래 계획은 높이 5개였으나 현장 문제로 1개만 완료
- [ ] 광각 평면(`W2-*`) 분석 반영, 1.2m 안쪽 점만 사용
- [ ] 추종 오차를 관절별 중력 토크에 대해 맞춰 명령 보정식 만들기
- [ ] 런타임이 받을 수 있는 묶음(영점, 장착, 리프트 오프셋) 결정 → 팀 합의 후 프로필 반영 → 집기 전후 비교
- [ ] 펌웨어 0x2492D 복구
