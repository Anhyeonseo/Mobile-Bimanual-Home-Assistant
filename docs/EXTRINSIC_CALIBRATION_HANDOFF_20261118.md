## 5. 남은 문제

**보정**
1. 리프트 배율·행정 확정(체커보드, 계획서 D) → `travel_m`, `meters_per_count` 갱신, 새 `calibration_id`로 Jetson 반영. 토크 OFF로 손으로 35–40mm씩 올리며 raw+`camshot` 하면 리프트 유지 문제를 피할 수 있다.
2. 처짐 항 런타임 반영(약 5mm, `MeasuredFK`·계획 모델).
3. **자세 의존 오차**: 손끝 오프셋·손목 굽힘/회전 영점·팔꿈치 영점(계획서 C 손끝 피벗, 접힌 자세 포함). 11/17 보정은 손목 회전 영점을 구하지 않는다.
4. 리프트 최하단 + 낮은 탁자(E1)에서 같은 2cm 위 시험으로 낮은 높이 재확인.

**집기**
5. 상단 집기: 검증된 편 자세 위주로 계획하거나, 집기 자세에서 "집게 벌린 채 2cm 위 정지" 시험으로 자세별 오차를 재서 보정.
6. 납작한 물체용 집기(고정/움직이는 집게 끝 높이 차 약 7mm).
7. 정식 집기 프로그램(`unified_pick`, `pick_service`)은 리프트 0–10mm만 허용. 상단 집기·리프트 보정 경로를 정식화해야 함.

**하드웨어·운영 (현서)**
8. 리프트 유지·등록 간헐 실패: 엔코더 1count 흔들림 + speed 50 → `LIFT_BAD_FEEDBACK`(-28 이동 중), 상단 등록 `lift rejected or MCU restarted`(-27, -30). 11/17 리프트 콘솔 실패와 같은 패턴.
9. 전원 재부팅 직후 첫 접속에서 STOP(호스트 UART 수신 오류 → `BinaryControl_HandleHostUartError`, rejected_frame 2–3). **SWD 리셋으로는 발생 안 함.**
10. OpenOCD 리셋에 sudo 필요(ST-LINK udev 권한 없음). sudo로 돌리면 `/run/user/1000/so101-backend.lock`이 root 소유가 되어 다음 실행이 `PermissionError` → 함께 삭제.
11. MCU 리셋 후에도 서보 토크 유지 → 매번 `release_boot_supported` 필요. 팔이 상판을 누른 상태에서는 정지 검사에 걸려 거부(reason 7) → 모터 전원으로 해제.
12. 시작 검사에서 쉬는 서보가 가끔 speed 50 보고 → `expected locked, stopped, torque 0` 거부(-21, -24). 거부된 시도가 부팅을 "사용함"으로 만들어 다음 시도는 리셋 필요.
13. 쉬는 자세에서 모델상 그리퍼↔어깨 겹침(양팔) → 시작 충돌 거부. 오늘은 해당 쌍만 ACM 허용(왼팔은 이동 중에도 검사 꺼짐 — 정식 도구에서는 형상·쉬는 자세 정리 필요).
14. 왼팔 어깨 하한(833)·손목 굽힘 상한(3180)이 받침 위 쉬는 자세 근처라 자주 범위 밖 → 받침 높이 조정.
