# 새 영점에서 촬영 자세 5개 저장

현재 왼팔은 `left-calibration-v1` 보정 전용 펌웨어이며 모터 영점 재설정과 전원 재인가 확인을 완료했다. 이전 가동 범위와 촬영 파일은 사용하지 않는다.

젯슨 터미널에서:

```bash
cd ~/robot/releases/selected-demo
python3 tools/run/teach_left_demo.py --file output/left-five-poses.json
```

팔과 물체를 받치고 손으로 아래 자세를 만든 뒤 해당 이름과 Enter를 입력한다. 영점 기준은 집게 중간이지만 촬영의 home은 집게가 열린 상태다.

| 입력 | 자세 |
|---|---|
| home | 촬영 시작 자세, 집게 열림 |
| approach | 물체 위, 같은 열림 |
| grasp | 집을 위치, 같은 열림 |
| closed | grasp의 팔 위치 유지, 집게만 닫음 |
| lift | 들어 올린 자세, 같은 닫힘 |
| show | 저장된 자세 이름 확인 |
| done | 5개 자세 관계 및 경계 검사 후 프로필 생성 |
| q | 저장된 내용을 보존하고 종료 |

같은 이름을 입력하면 해당 자세만 다시 저장한다. 자동 이동이나 토크 변경, 영점 쓰기는 없다. 실제 측정 3회, 흔들림, 여섯 모터의 영점 오프셋, 토크 꺼짐을 확인한다. 저장값이 180도 이상의 범위에 걸치면 임의 회전 방향을 선택하지 않고 거절한다.

`done`은 `output/left-five-poses.json`과 `output/left-five-poses.profile.json`을 남긴다. 프로필은 측정 자세 및 영점 기록의 식별값, 순서대로 이웃한 자세 사이 이동, 자세별 정확한 집게 유지값, 관절별 실측 최소·최대에서 양쪽 256칸(22.5도)의 여유 를 포함한다. 재생 시에는 현재 자세를 읽어 허용 범위 안에서 저속으로 Home에 먼저 돌아온다. 집게 닫힘 방향은 실측 열림/닫힘 값으로 정한다.

현재 단계는 측정과 프로필 생성까지다. 실제 측정 파일을 받은 뒤 그 값에 묶인 재생 펌웨어와 도구를 생성·검사·전환해야 한다. 기존 `fixed_pick_left.py play`는 아직 사용하지 않는다. 저장된 끝 자세가 가능하다는 사실만으로 자세 사이의 충돌 없는 경로가 보장되지는 않으므로 첫 재생은 물체 없이 천천히 확인한다.

관련 소프트웨어 검사 96개 통과. 배포 뒤 실제 왼팔의 읽기 전용 3회 캡처로 연결·영점 일치를 확인했다. 물리 재생 검증은 아직 수행하지 않았다.
