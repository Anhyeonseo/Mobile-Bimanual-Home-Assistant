# S2 — 좌표와 관측 연결

2026-11-01. 개발은 S2로 진행한다. 리프트 하강 소음은 사용자 결정으로 최종 실물
점검 이슈로 남긴다. S1 공통 실행·원점 복원·실물 동작 검증의 미완료 항목은 유지한다.
현재 작업은 모델과 관측 연결이며 추가 구동이나 펌웨어 전환은 수행하지 않았다.

## 이번 단계의 결과물

카메라에서 본 물체의 점을 베이스 기준으로 표시하고, 같은 기준에서 양팔 집게 끝과
비교한다. 좌표 오차 확인 이후 S3에서 실제 관측 위치로 집기를 연결한다.
물체 표면의 대표점과 실제 파지 위치·자세는 별개다.

## 설치 사실과 재사용할 코드

| 항목 | 확보한 내용 | 아직 확인할 내용 |
|---|---|---|
| D415 | 베이스 또는 고정 기둥 장착, 리프트와 함께 움직이지 않음 | 정확한 장착 위치·각도, 외부 보정 |
| 리프트 | 상판 높이 약 0.90→0.26m, 이동 30,717 counts, 약 85.3417mm/회전 | 재시작 후 원점 복원, 반복성, 상판 기준과 모델 링크 원점 차이 |
| 양팔 | Home 2048 보정·유지, 왼팔 범위 측정 및 오른팔 재사용 결정 | 새 Home과 모델 관절 영점 대응, 양팔 장착 변환, 집게 끝 위치 |
| LDS-01 | 모델명 확인 | 케이블 연결·장착 변환; 후속 주행 단계와 연계 |

설치 사실은 `config/home_assistant/installation.development.json`, 리프트 측정값은
`config/home_assistant/lift_geometry.measured.json`에 보존한다. 이 파일은 자동 구동
설정이 아니며 미측정 변환은 null이다. 리프트 높이 환산은 단일 하강의 평균값이다.

`so101_description`의 팔 macro와 읽기 전용 TF launch를 재사용한다. 전체 모의
모델 `alohamini.simulation.urdf.xacro`는 실측 모델이 아니다. 특히 기존 모의 모델은
카메라가 lift_link에 붙고, 리프트 기본 이동량 0.50m·높이 원점 0.25m·양팔 간격
0.28m 등을 가정한다. 이 값을 실제 장착 치수로 사용하지 않는다. 단일 팔 TF launch도
전체 모바일 로봇 연결을 제공하지 않는다.

## 좌표 연결 원칙

- 베이스에 고정된 D415: `base_link → camera_link → optical_frame`.
- 양팔: `base_link → lift_link → left/right arm → gripper reference → TCP`.
- 카메라 고정 장착에서는 리프트 높이를 바꿔도 카메라의 베이스 상대 변환은 바뀌지 않는다.
  집게 끝의 베이스 좌표에는 촬영 시각에 맞는 리프트·관절 상태가 필요하다.
- 상판 바닥 높이 0.26m를 lift_link의 높이 원점으로 바로 넣지 않는다. base_link의
  실제 기준점과 상판/모델 링크 간격을 먼저 정의한다.
- RGB 정렬 깊이와 원래 깊이의 optical frame을 구분하고, 카메라 내부 변환은 장치의
  보정값을 사용한다. 외부 장착 변환을 영행렬 이동값으로 임의 채우지 않는다.
- 모터 2048 보정과 기구 모델의 관절 각도 0 일치는 별도로 확인한다.

## 진행 순서

1. 베이스 기준점과 실제 센서·팔 장착 구성을 확정한다. 현재 D415의 고정 장착까지 확인했다.
2. 기존 도면·모델에서 재사용할 치수를 확인하고 부족한 양팔 장착 위치와 상판 기준 간격만 측정한다.
3. 새 Home의 관절 방향·영점과 집게 끝 기준을 모델에 연결한다. 우선 모터를 움직이지 않는 모델 표시로 확인한다.
4. 카메라 외부 보정값을 기록하고 별도의 표적에서 베이스 좌표 오차를 확인한다.
5. 촬영 시각·좌표계·보정 버전을 유지하는 관측 연결을 검증한 뒤 S3로 넘긴다.

실측값이 없는 구간은 모의 검증으로 진행한다. 기존 모의 성공을 실물 좌표 정확도의
증거로 사용하지 않는다. 소음 조사는 이 순서의 선행 조건으로 추가하지 않는다.

## 1차 소프트웨어 준비 결과

`tools/diagnostics/s2_coordinates.py audit`로 설치 사실·리프트 실측값·남은 측정 묶음을
조회한다. 저장소에서 현재 조립체의 실측 도면은 확인하지 못했다. 팔 macro는 기존
부품 형상을 재사용하되, wrist_roll과 wrist_flex 등에 2026년 7월 Home 보정이 들어 있다.
이번 Home을 모델 영점으로 자동 간주하지 않는다.

추가 측정은 네 묶음이다. 팔의 모든 링크 길이를 다시 재지 않는다.

| 묶음 | 확인할 내용 |
|---|---|
| 베이스 기준 | 실제 기준점과 정면 표시; X 전방·Y 왼쪽·Z 위 |
| 팔 장착 | 최저 상판에서 양팔 장착 원점까지의 위치·방향, 베이스와 상판의 연결 위치 |
| Home·집게 끝 | 현재 Home과 모델 영점 비교, 파지 기준점·개구 폭 |
| 고정 카메라 | 같은 표적점의 카메라 XYZ와 베이스 XYZ |

정면·측면 사진은 기준점과 측정 위치를 지정하는 데 사용한다. 사진만으로 밀리미터
치수나 카메라 외부 보정을 확정하지 않는다. 카메라 각도를 각도기로 따로 추정하기보다
아래 대응점으로 회전과 이동을 함께 계산할 수 있다.

### 고정 카메라 오프라인 보정

핵심 계산은 L3A `home_robot_tasks.camera_registration`에 둔다. 카메라 optical XYZ와
베이스 XYZ의 대응점으로 강체 변환을 계산하고, 계산용 최소 6점과 별도 확인용 최소
3점을 구분한다. 표적은 두 방향 이상으로 충분히 벌리고 실제 사용할 거리·높이에
분산해 수집한다. 가능한 경우 서로 다른 깊이도 포함한다. 확인점은 보정 결과에서
역산하지 않고 독립적으로 측정한다. 라벨만 다른 중복점은 거부한다.

단위는 m, 방향은 `p_base = base_from_optical @ p_optical`이다. `source_frame`은
실제 영상과 같아야 한다. Grounding의 `color_camera_optical_frame`과 ROS의
`camera_color_optical_frame`을 자동 별칭 처리하지 않는다. `mount_revision`과
`base_reference`는 장착 상태와 기준점 정의이며 둘 중 하나가 바뀌면 새로 계산한다.

JSON 형식은 `config/home_assistant/camera_correspondences.simulation.json`을 따른다.
이 파일은 합성 자료이며 실제 보정값이 아니다. 예제의 15mm 허용 오차도 도구 동작
확인용 값이며 최종 파지 정확도 기준이 아니다. 계산점·확인점 모두 지정한 최대 오차를
검사하고 틀린 점을 자동 삭제해서 통과시키지 않는다.

```bash
python3 tools/diagnostics/s2_coordinates.py audit
python3 tools/diagnostics/s2_coordinates.py fit-camera \
  --points config/home_assistant/camera_correspondences.simulation.json \
  --output output/home-assistant/s2/camera-fit-simulation.json
```

출력은 변환행렬·점별 오차·자료 해시·보정 ID를 포함한 검토 후보이며 기존 파일을
덮어쓰지 않는다. 오차 초과 시 보고서를 남기고 종료 코드 2를 반환한다. 합성/실측
출처를 유지하고 자동 TF 발행이나 구동 설정 적용은 하지 않는다. 같은 변환을 기존
`TransformSample`/Grounding 관측 경계에 연결하는 소프트웨어 검사도 포함했다.

신규 보정 13개 및 기존 홈 어시스턴트/계층 연결 회귀를 합쳐 53개 통과.
기울어진 optical 축의 회전·이동 복원, 독립 확인점 실패, 단위·부호·퇴화·중복 입력,
반사 변환 거부, 기존 관측 경계 연결과 결과 파일 보존을 검사했다. 장치 명령은 0회다.

## 최종 실물 점검으로 이관한 항목

S1-LIFT-NOISE: 2026-11-01 전체 하강과 정지는 성공했으나 하강 중 소음이 재발했다.
원인은 미확정이고 온도 31→60→31°C의 단일 이상값도 원본에 보존했다. 사용자 결정으로
S2 개발을 막지 않으며 최종 실물 수락 시 다시 점검한다. 소음 자체가 동작에 영향 없다고
검증된 것으로 표시하지 않는다.
